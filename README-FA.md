# نسخه امن‌تر سایت قضاوی

## راه‌اندازی
1. Node.js نسخه 18 یا بالاتر نصب کنید.
2. در پوشه پروژه اجرا کنید: `npm install`
3. متغیرهای محیطی مدیر را تنظیم کنید (حساب مدیر با ثبت‌نام عمومی ساخته نمی‌شود):
   - `ADMIN_EMAIL=admin@example.com`
   - `ADMIN_PASSWORD=یک رمز قوی و حداقل ۱۲ کاراکتری`
   - `SESSION_SECRET=یک رشته تصادفی طولانی`
4. اجرا: `npm start`
5. سایت: `http://localhost:3000`، ساخت حساب: `/account.html` و پنل: `/admin.html`

در Linux/macOS می‌توانید قبل از اجرا متغیرها را در همان ترمینال export کنید:
`export ADMIN_EMAIL='admin@example.com'`
`export ADMIN_PASSWORD='...'`
`export SESSION_SECRET='...'`

## نکات امنیتی
- ثبت‌نام عمومی فقط نقش user می‌سازد؛ نقش admin فقط از تنظیم اولیه سرور می‌آید.
- تمام APIهای افزودن/ویرایش/حذف محصول سمت سرور نقش مدیر را بررسی می‌کنند؛ مخفی‌کردن HTML به‌تنهایی امنیت نیست.
- قبل از انتشار، HTTPS و مقادیر محرمانه قوی تنظیم کنید. `SESSION_SECRET` پیش‌فرض تصادفی است و برای استقرار باید ثابت و امن تنظیم شود.
- محصولات اکنون در SQLite ذخیره می‌شوند؛ داده‌های localStorage نسخه قبلی خودکار منتقل نمی‌شوند.
